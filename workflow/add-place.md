# Workflow: добавление нового места в каталог

Повторяемая процедура для расширения каталога мест (`app/supabase/seed.sql`).

## Вход

- Фото (файл или URL)
- Координаты (или адрес — тогда шаг 1 их найдёт)
- Короткое описание
- Теги (например: крыши, парки, граффити, архитектура, панорама)

## Промпт

```
Добавь новое место в каталог проекта "Москва в кадре".

Вход:
- Название: <название>
- Координаты или адрес: <lat,lng либо адрес>
- Описание: <короткое описание>
- Теги: <тег1, тег2>
- Фото: <файл или URL, если есть>

Сделай по порядку:
1. Если дан адрес, а не координаты — геокодируй через Nominatim
   (https://nominatim.openstreetmap.org/search?format=json&q=<адрес>),
   без API-ключа.
2. Проверь дубликаты: найди в app/supabase/seed.sql точки в радиусе ~100 м
   от новых координат (используй haversine, как в app/src/lib/route.ts).
   Если нашлись — покажи их и спроси, добавлять ли всё равно.
3. Добавь новую строку INSERT в app/supabase/seed.sql с source='curated'.
4. Обнови счётчик мест в README.md.
5. Покажи диф и предложи сообщение коммита.
```

## Формат

Этот файл — копируемый промпт. Тот же процесс доступен как скилл
`.claude/skills/add-place/SKILL.md`, вызывается `/add-place` в Claude Code.
