# Добавление места в каталог

Используй, когда пользователь просит добавить одну курируемую точку в
`app/supabase/seed.sql`. Не применяй живую БД и не коммить без отдельных
подтверждений пользователя.

## Вход и остановки

Нужны название, координаты или адрес, описание, теги и опциональный публичный
HTTPS URL фото. Не угадывай отсутствующие значения. Локальный файл нельзя
записать в `photo_url`: попроси публичный URL или согласуй `null`.

## Шаги

1. Проверь обязательный вход. Координаты — конечные числа: lat `[-90, 90]`,
   lng `[-180, 180]`.
2. Для адреса сначала открой актуальную [Nominatim Usage
   Policy](https://operations.osmfoundation.org/policies/nominatim/). Выполни
   один search-запрос `format=jsonv2&limit=3&countrycodes=ru&q=<encoded>` с
   User-Agent `MoscowInFrameHomework/1.0
   (https://github.com/yuristy/enot-ai-homework-2)`. Не делай batch,
   autocomplete или retry-loop; максимум 1 запрос/с. При сетевой ошибке или
   неоднозначности остановись и попроси координаты/выбор результата.
3. Убедись по адресу/результату, что точка относится к Москве. При сомнении
   спроси пользователя.
4. Прочитай `app/supabase/seed.sql`; через `haversineDistanceKm` из
   `app/src/lib/route.ts` найди точки в радиусе 100 м. Покажи название,
   координаты и расстояние. При совпадении продолжай только после ответа.
5. После существующего multi-row statement добавь отдельный
   `insert into public.places (name, description, lat, lng, tags, photo_url,
   source) values (...)`. Используй `array[...]` для тегов, `null` для
   отсутствующего фото и `source = 'curated'`. Экранируй SQL-кавычку как
   `''`; не добавляй `created_by`, credentials или закрытые URL.
6. Пересчитай curated rows и обнови фактический счётчик в `README.md`.
7. Выполни `git diff --check` и targeted test дедупликации. Покажи diff,
   расстояния и результаты; не скрывай недоступную проверку.
8. Запроси отдельное подтверждение на commit. Применение SQL в живом Supabase
   — другое внешнее действие и требует ещё одного подтверждения. Без них
   остановись на проверенном diff.
